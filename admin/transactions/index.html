管理后台 交易与退款 — 前端契约面 (2.0.0)

Download OpenAPI specification:

管理后台 React SPA 消费的交易与退款契约：跨商户的交易查询、即时合计、订单详情与导出（商户详情的订单页签用同一组接口、固定商户），跨商户的退款单查询、详情与导出，退款待审队列与审核决定，按商户只读查看代扣协议。 浏览器持 httpOnly 会话 cookie，字段类型与校验规则以本 spec 各字段为准。

金额口径：金额是对应币种最小单位的整数串，带币种。交易列表行上的金额与商户后台交易列表同口径：已成交的订单是结算币种的成交金额（结算额待定的暂为标价金额并带标记），没成交的是标价金额；退款金额是原订单的标价币种。

幂等 / CSRF 口径：

  • 审核决定带状态前置（只对审核中的退款生效，两人同时下以先到者为准），不挂幂等键。
  • 两个导出按读处理，不挂幂等键。
  • cookieAuth 的非安全方法一律带 X-CSRF-Token。

数据可见范围：同管理后台约定「数据可见范围」，按订单所属商户求值：范围外商户的订单、退款与代扣协议不出现在列表、合计与导出里，按标识访问一律 404。

操作审计：审核通过与拒绝记入操作审计（带审核人、退款单、商户、结论与审批说明），可在该商户详情的操作记录页签查到；查询、详情、导出不记。

交易

跨商户的支付订单：列表、即时合计、详情与导出。

交易列表（筛选、搜索、排序、分页）

本人数据范围内商户的支付订单，分页。日期范围按订单创建日期，两端必填。商户详情的订单页签用本接口并固定 merchantId。

交易列表即时合计（按结算币种分组）

与 listPayments 用同一组筛选参数、基于同一批订单的合计；不要求指定商户。按结算币种分组，每个币种一组，金额都是该结算币种（每笔按实际结算金额相加）；只涉及一个结算币种时（如商户详情的订单页签）就只有一组。没有计入的订单时 items 为空数组。

只算收到钱的四种状态：PAID / PARTIALLY_REFUNDED / REFUNDED / PREAUTH_HOLDING。列表还会列出 FAILED / REJECTED，所以笔数合计可能小于列表行数。grossSales 就是这四种状态、结算额已到的行金额之和；结算额待定的笔不计入金额合计、计入笔数。

refundAmount 是这批订单至今已退的金额（随订单计入，不按退款发生日），netSales = grossSales − refundAmount。

订单详情（含同单退款与回调投递）

单张订单：列表行的字段，加金额明细、支付方式与通道、产品形态与受理模式、各时刻、通道交易号与通道错误、付款人通道侧标识与 IP、回调地址、发起设备、订单描述与采集项、同单的全部退款，以及该单向商户回调的投递任务。订单不存在或所属商户在本人数据范围外 → 404。

结算锁只展示，本面没有释放结算锁的操作。关联退款里 type = system_auto 的是平台自动退回的多付款项，不计入 refundedAmount。

callbackDeliveries 里进了死信的任务，到运维与审计的对外投递详情（getOutboundDelivery）人工重投，本面不重投。

status = REJECTED 的订单从未发生支付，没有支付方式、通道与付款人信息。

导出交易（xlsx）

按所给筛选导出命中的全部订单，不只是当前页；筛选字段与 listPayments 相同，只含本人数据范围内商户的订单，商户详情的订单页签导出时固定 merchantId。列是列表行的字段，加人民币实扣金额与付款人通道侧标识。同步返回文件流。表头与枚举文案按 Accept-Language，实际用的语言经 Content-Language 回。按读处理，不挂幂等键。

什么时候拒绝：

  • 命中行数超过导出上限 → 409·308503，不出文件；context.maxRows 带当时的上限，缩小筛选后重试。
  • 日期范围缺一端、to 早于 from、跨度超过允许的最大查询窗口、字段格式不对 → 400。

退款单

跨商户的退款单：列表、详情与导出。

审核退款（通过或拒绝）

对审核中的退款下结论，审核人是当前登录的后台用户：

  • APPROVED：通过。跨主子代退的退款先复检发起方的代退授权，授权已撤即拒绝；其余受理时的条件不再重判。通过后退款送往通道，响应的 status 是退款此时的状态。
  • REJECTED：拒绝，reviewNote 可填，作为审批说明在退款详情展示。退款转为已拒绝，占用的可退额度放回订单。

两人同时下结论以先到者为准。带状态前置，不挂幂等键。审核通过与拒绝都记入操作审计。

什么时候拒绝：

  • 308501 退款已不在审核中（他人先下了结论，或商户已撤销，或自己上一次已成功〔提交后超时重点〕），重读队列。
  • 308502 跨主子代退的退款在审核期间失去了代退授权，不能通过；可改为拒绝。退款不变。
  • reviewNote 超长、decision 不在取值内 → 400。
  • 退款不存在，或订单所属商户在本人数据范围外 → 404。
