管理后台 运维与审计 — 前端契约面 (2.1.0)

Download OpenAPI specification:

管理后台 React SPA 消费的运维与审计契约：操作审计查询（/audit-events）、通知投递失败查询与重投（/notification-deliveries）、商户回调与平台回写的投递查询与重投（/outbound-deliveries）、批任务面板（/batch-jobs）。 浏览器持 httpOnly 会话 cookie，字段类型与校验规则以本 spec 各字段为准。

  • cookieAuth 的非安全方法一律带 X-CSRF-Token。
  • 每个接口要的权限点见 x-required-privilege。
  • 本面只有查询与命令，没有删除或清空操作记录的接口。

操作审计

全平台人的敏感操作记录，只读。

操作审计列表（筛选、分页，发生时间从新到旧）

全平台的操作记录，固定按发生时间从新到旧，可叠加下列筛选。全局横查与商户详情的「本商户操作记录」页签都用本接口，页签固定带 merchantId，同条件下两处结果相同。

记了什么：人在各端界面上做的敏感操作。权限检查被拒的尝试没有发生操作，不在其中；后台程序自己的动作也不在其中。

看得到哪些：与商户相关的记录（该商户用户的操作、代登期间的操作、后台用户对该商户的操作）只返回本人数据可见范围内的商户；不涉及商户的记录（平台参数、公告、后台账号等）有本权限点即可看到。按一个不在范围内的商户筛选，结果为空。

重投一条发送失败的通知

对一条发送失败的记录重投：产生一条新的投递记录并返回它，新记录的 redeliveryOfId 指回原记录；原记录保持发送失败不变，此后带上 redeliveredTo 指向新记录。每次重投留下一条操作记录。

重投产生的记录连成一条链，只有链上最新一条能重投：新记录再发送失败，就对新记录重投，次数不限。

新记录发出前按当前的模板与接收方重新校验；仍不满足的（如模板还没修好），新记录同样落发送失败、不外发，原因见它的 failureReason。发送结果随后更新，重新读取列表可见。

什么时候拒绝：

  • 这条记录不是发送失败、已经被重投过（不是链上最新一条，含他人同时发起的），或承载一次性凭据（验证码、一次性链接：随通知事件投递、不供人工重投，由用户重新发起）→ 409·308105，不产生新记录。重读列表；要再重投，对链上最新一条操作。
  • 记录不存在，或不在本人数据可见范围内 → 404。

幂等：Idempotency-Key，作用域 = 键 + 路径里的记录。同键重发返回首次产生的新记录；同键用于另一条记录 → 409·908003；首次请求还在处理 → 409·908002，稍后同键重发。

对死信任务人工重投一次

在原任务上发起一次新的尝试，标为人工触发，不另建任务。报文内容与签名方式与自动尝试相同，商户按事件身份去重。目标地址按与自动尝试相同的规则判定，命中拒投规则的不发出请求，这次尝试记为失败。每次人工重投留下一条操作记录。

受理后返回任务当前状态；尝试结果随后更新，重新读取详情可见。这次尝试成功则任务变为已送达，失败则回到死信。

什么时候拒绝：

  • 任务不在死信（已送达、仍在自动重试中，或人工重投正在进行）→ 409·308106，不新增尝试。
  • 任务不存在，或不在本人数据可见范围内 → 404。

幂等：Idempotency-Key，作用域 = 键 + 路径里的任务。同键重发返回首次受理的结果；同键用于另一个任务 → 409·908003；首次请求还在处理 → 409·908002。

触发一次执行

让所属服务立即执行一次该批任务。受理后返回这次执行（通常是启动中）；执行进度以所属服务为准，重新读取可见。每次触发留下一条操作记录。

什么时候拒绝：

  • 该任务已有一次执行在进行，所属服务不再启动新的 → 409·308108。
  • 批任务不存在 → 404。

幂等：Idempotency-Key，作用域 = 键 + 路径里的批任务。同键重发返回首次受理的执行、不再触发；同键用于另一个批任务 → 409·908003；首次请求还在处理 → 409·908002。

重启一次失败或已停止的执行

让所属服务从这次执行上次停下的地方继续跑，产生一次新的执行。受理后返回这次新执行（通常启动中）；原执行保持原状态；执行进度以所属服务为准，重新读取可见。每次重启留下一条操作记录。

什么时候拒绝：

  • 这次执行不是失败或已停止（如已成功、仍在执行），或已有更晚的执行在续跑它，或它的失败是由所属服务的已放弃 / 状态不明归并来的（见 BatchExecutionStatus），所属服务不受理 → 409·308107，状态不变。
  • 批任务或执行不存在 → 404。

幂等：Idempotency-Key，作用域 = 键 + 路径里的执行。同键重发返回首次受理的结果；同键用于另一次执行 → 409·908003；首次请求还在处理 → 409·908002。
