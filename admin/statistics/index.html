管理后台 React SPA 消费的统计分析契约：运营首页（交易总览与对比、趋势、商户数、支付来源与支付方式族分布、交易排行），商户概览，平台交易报表，财务报表，通道流量，清算统计、逐日序列与按日导出，清算金额趋势与月历，月度清算报表，授信退款商户，机构与 BD 销售排行与导出，直清商户 × 月导出。 浏览器持 httpOnly 会话 cookie，字段类型与校验规则以本 spec 各字段为准。本面全部是读。

金额口径：金额是对应币种最小单位的整数串，带币种，一律是结算币种。不同结算币种分组给出，不跨币种相加、不折算。退款金额 = 受理成功的退款减受理后失败的回冲；净额 = 成功收款金额减退款金额。通道成本是按费率估算的成本，不是通道声明的手续费。

「未配置」：一格所依据的、已生成清结算明细的交易里有一笔商户手续费尚未算出（含未配费率）或缺通道成本（未配成本率），该格不返回；依赖它的平台留存、渠道手续费、平台手续费、清算总额也不返回。页面在这些格显示「未配置」，其余列照常；导出文件里这些格写「未配置」。手续费在成交后很快算出，当天刚成交的交易可能短暂显示「未配置」。清算类统计只含已算好手续费的交易，商户手续费恒有值，只有通道成本可能未配置。直清通道的交易不产生商户手续费与通道成本，计 0、不算未配置。尚未生成清结算明细的交易不计入当期的商户手续费与通道成本（当天的数随之变化），也不算未配置。

日期口径：

  • 日期按字面收发（同基础约定「日期」）。平台交易报表、财务报表、通道流量与全部商户范围下的运营首页按平台的日界；带商户粒度的统计（商户概览、交易排行、有交易商户数、数据范围不是全部商户时的运营首页、机构与 BD 排行、直清商户导出）按各商户自己的日界；清算类统计按清算日。同一笔交易在两种日界下可落不同日期，两边按日对比不相等属正常。
  • 新增商户（按激活时刻）与新增达标商户一律按平台的日界，任何数据范围都一样。
  • 「今天」「昨天」「本月」「上月」「近 7 天」由服务端在每次查询时求出；近 7 天 = 截至昨天的 7 个完整日。按各商户日界的统计里，各商户按各自的今天求，跨商户合计没有单一的「今天」边界。
  • 当天的交易实时计入；已结束的日子为日终汇总。
  • 日期或月份区间两端必填的，缺一端、to 早于 from → 400。区间跨度不设上限。

可见范围：平台交易报表、财务报表、通道流量、清算金额趋势与月历、月度清算报表是平台级页面，只看功能权限。运营首页、商户概览、清算统计（含逐日序列与按日导出）、授信退款商户、直清商户导出按本人数据范围求值：范围外商户不计入任何合计、计数与排行，按标识访问一律 404。机构销售排行与机构详情只出本人可见的机构（全部商户 → 全部机构；所属机构 → 所属机构及其直接下级；本人名下 → 无机构），BD 销售排行与导出只出本人可见的销售（全部商户 → 全部；所属机构 → 所属组织为所属机构及其直接下级的销售；本人名下 → 本人）；可见机构或销售之下的商户不再按商户过滤，跨范围临时授权不作用于排行。

导出：导出与页面同范围、同口径、同列，同步返回 xlsx 文件流，表头与文案按 Accept-Language、实际用的语言经 Content-Language 回。按读处理，不挂幂等键；带 X-CSRF-Token。

操作审计：查询、详情与导出都不记操作审计。

运营首页

运营首页交易总览与对比

所选区间的交易总览，每个结算币种一项：成功收款金额与笔数、退款金额与笔数、净额、有交易商户数（区间内有成功收款的去重商户，按各商户自己的日界），并给上期同项与对比基准 comparisonBasis。

上期怎么取：

  • today：较昨日同时段（昨天从日始到与此刻同一钟点）。
  • this_month：较上月同期（上月 1 日到与今天同号的那天，上月没有该号取上月末日）。
  • 其余：较紧邻的等长上期；last_month、month，以及正好是一个整自然月（某月 1 日到该月末日）的 custom，上期是前一个自然月；其余是紧邻其前、天数相同的区间。

变化率由前端按两值算，上期为 0 时不显示变化率。只在本期或上期出现过的币种也给一项，另一边各值为 0。

商户概览

单个商户近期的交易概览。

商户概览

单个商户的近期交易概览，按该商户自己的日界、结算币种；窗口截至今天，今天的交易计入。

  • 近 windowDays 天（平台设定，默认 30）：成功收款金额与笔数、退款金额、最大单笔收款、日均收款金额（= 窗内收款金额 ÷ windowDays，四舍五入到最小币种单位），以及按支付方式族的成功收款笔数分布。
  • 近 trendDays 天（平台设定，默认 14）按日的收款金额趋势，无交易的日子补 0，按日期从先到后。
  • 首次与最近交易日期（含今天）；从未交易的不返回这两项，金额与笔数为 0。
  • 结算额待定的收款计入笔数，不计入金额与最大单笔。
  • 未清算金额 unsettledAmount = 该商户当前的待结算，与清算结算页商户资金概览的「待结算」同口径、同为现值。

商户不存在或不在本人数据范围内 → 404。
