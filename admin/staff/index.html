管理后台 后台账号与角色权限 — 前端契约面 (2.2.0)

Download OpenAPI specification:

管理后台 React SPA 消费的后台账号与角色权限契约：后台账号（邀请建号、编辑、改登录邮箱、停用启用、移除加回、为他人重置密码 / 重置验证器 / 解锁）、在线会话与强制下线、登录日志、管理后台角色、两棵资源目录（只读，随版本发布）、商户后台与终端预设角色、跨范围临时授权。 浏览器持 httpOnly 会话 cookie，字段类型与校验规则以本 spec 各字段为准。

幂等 / CSRF 口径：

  • 建号、编辑账号、加回、为他人重置密码、建角色、建临时授权挂 Idempotency-Key：同键同请求体重发返回首次结果；同键改请求体 → 409·908003；首次请求仍在处理 → 409·908002，稍后同键同请求体重发。
  • 带版本的写（改角色、改预设角色）以版本防并发覆盖、不挂幂等键；天然幂等的置值与删除（改账号状态、移除、重置验证器、解锁、强制下线、撤销授权）不挂。
  • cookieAuth 的非安全方法一律带 X-CSRF-Token。

权限边界（服务端校验）：

  • 后台账号管理是平台级页面，不受数据可见范围限制。
  • 逐个角色判，每个角色的点集都必须是操作者有效权限点集合的子集（可以相同）。用在三处：建号给的每个角色、编辑改成的每个角色、被操作账号现有的每个角色——不能对权限比自己宽的账号做编辑、改登录邮箱、停用启用、移除加回、重置密码、重置验证器、解锁、重发邀请。不满足 → 403·306007。
  • 给他人设的数据范围不得宽于操作者自己的范围 → 否则 403·306009。
  • 不能对自己做停用、移除、改角色、改数据范围、改登录邮箱、重置密码、重置验证器 → 403·308001。
  • 停用、移除、改角色、停用角色、改角色点集，若会使系统不再有同时持 opacc:user:manage、rbac:role:manage、opacc:credential:manage 的正常在册账号 → 409·308002。

邀请新建后台账号（发邀请邮件，对方设密后激活）

录入登录邮箱、显示名、角色与数据范围，系统向该邮箱发邀请邮件；对方在邀请链接落地页设密后账号才可登录，此前状态为 INVITED。邀请链接的有效期由平台设定。BD 与机构账号走同一入口，差别只在角色与数据范围。

登录邮箱属于已激活、邮箱已验证、未停用且尚无管理后台身份的已有用户时，不新建用户，而是为该用户加上管理后台身份，同样返回 201：不发邀请邮件、不改其密码（对方已有密码），授予所给角色与数据范围后即可登录管理后台，状态为 ACTIVE；还没绑定验证器的，登录时先绑定。之后停用对两边同时生效；移除、加回只作用于管理后台身份。

幂等基准：Idempotency-Key。

什么时候拒绝：

  • 968001 登录邮箱已被在册的后台账号使用。
  • 308003 登录邮箱属于已移除的后台账号，改为在列表里找到它加回（restoreStaff）。
  • 308007 登录邮箱属于邀请中、待验证或已停用的已有用户，不能直接授予后台身份；先完成激活 / 验证或由运营启用。不发邀请，该用户状态不变。
  • 306007 所给角色里有超出操作者权限边界的；306009 数据范围宽于操作者自己的。
  • 数据范围为 partner 却没给 partnerId、或给了 partnerId 而范围不是 partner、白名单格式不对 → 400，不建账号。

编辑后台账号（资料、角色、数据范围与机构、登录 IP 白名单、登录邮箱）

只提交要改的字段，一次提交全部生效或全部不生效。各字段的效果：

  • roleIds：整组换成所给的这组；角色与数据范围的改动对该账号已有会话的下一次请求即时生效。
  • dataScopeType / partnerId：范围改为 partner 时须同时给 partnerId；改为其他范围时机构随之清空。
  • loginIpAllowlist：整组置换；为他人保存不要求包含操作者当前 IP。
  • loginEmail：已激活账号不直接生效，向新邮箱发确认链接，当事人确认后才切换，确认前旧邮箱照常可登录、新邮箱不占用；再改会顶掉上一笔未确认的。邀请中的账号改邮箱 = 向新邮箱重发邀请、旧链接作废。

幂等基准：Idempotency-Key。

什么时候拒绝：

  • 308001 对自己改角色、数据范围或登录邮箱。
  • 308002 改角色会让系统不再有能管理账号、角色与凭据的在用账号。
  • 306007 改成的角色、或该账号现有的角色里有超出操作者权限边界的；306009 数据范围宽于操作者自己的。
  • 308004 账号已移除（先加回）。
  • 968001 新登录邮箱已被别的账号使用。
  • 范围与机构不配、白名单格式不对 → 400，不改动。

查找可自助申请临时授权的范围外商户

按商户码或名称查找本人数据范围外的商户，供自助申请临时授权（createAccessGrant）。只回商户码、名称与能否申请，不回其他资料。

  • 只含范围外、非 KA、未关户的商户；范围内的与 KA 商户不返回。
  • requestable = false 表示本人已持该商户生效中的临时授权，无需再申请。
  • 最多返回 20 条，不分页；命中更多时请输入更完整的商户码或名称。
