管理后台 平台设置与公告 — 前端契约面 (2.0.0)

Download OpenAPI specification:

管理后台 React SPA 消费的平台设置契约：平台参数（/settings/parameters）、平台级收单参数（/settings/acquiring-parameters）、平台退款参数（/settings/refund-parameters）与发给全体商户的公告（/announcements）。 浏览器持 httpOnly 会话 cookie，字段类型与校验规则以本 spec 各字段为准。

  • cookieAuth 的非安全方法一律带 X-CSRF-Token。
  • 每个接口要的权限点见 x-required-privilege。

平台参数

平台级运营参数：按声明列出，可改值、可恢复默认。

平台参数列表（含生效值、默认值与写入用的版本）

平台参数页上的全部参数，按分组给出。每项带展示名、当前生效值、默认值与写入用的版本；平台设过值的另带 value，没有 value 即当前用的是默认值。收单相关的平台参数在平台收单参数页（listAcquiringPlatformParameters）；退款审核开关、审核金额阈值与最大退款期限在平台退款参数页（listRefundPlatformParameters），都不在本列表。

顺序即展示顺序。

改一个平台参数的值，或恢复默认

把这个参数在平台上的值设为 value；value 传 null 即恢复默认（清掉平台设过的值，生效值回到默认值）。对此后的判定生效，改前已经发生的不受影响。成功返回写入后的参数，每次成功都留下一条操作记录。

全量覆盖：请求体就是目标本身，value 与 version 都要传，缺省不代表保持原样。

什么时候拒绝：

  • version 不是读到时的那个（别人已经改过）→ 409·308103。重新调 listPlatformParameters 读最新值，再决定是否重改。
  • value 的类型或取值不合该参数的值域 → 400，由 details 定位到 value；参数不变。
  • 参数不存在 → 404。

重复提交：不带幂等键。上一次其实已经成功、响应丢了再提交，会因版本已变得到 308103，重读即可看到上次写入的值。

平台收单参数

收单相关的平台级参数（APP 订阅、小费默认档位、小红书默认上浮、费率上限与到期预警天数）：可改值、可恢复默认。

平台收单参数列表（含生效值、默认值与写入用的版本）

收单相关的平台级参数：APP 订阅的首月分界日、单台月费与合约期数，小费默认三档，AllValue 小红书默认上浮，商户费率上限，费率到期预警天数。形态与平台参数相同：每项带展示名、当前生效值、默认值与写入用的版本；平台设过值的另带 value。

单台月费按商户的结算币种解释，不带币种。AllValue 小红书默认上浮与商户费率上限是比例小数字符串（stringValue，如 "0.05" = 5%，至多 4 位小数），与费率同形，换算为百分数只在页面展示。顺序即展示顺序。

平台退款参数

退款相关的平台级参数（退款审核总开关、审核金额阈值、最大退款期限）：可改值、可恢复默认。

平台退款参数列表（含生效值、默认值与写入用的版本）

退款相关的平台级参数：退款审核总开关、退款审核金额阈值、最大退款期限。形态与平台参数相同：每项带展示名、当前生效值、默认值与写入用的版本；平台设过值的另带 value。

总开关打开后，金额达到阈值的退款要经后台审核才送往通道；阈值是结算币种的最小单位整数，按各商户的结算币种解释，不带币种。最大退款期限是天数，订单成交超过这个天数的不能再发起退款。顺序即展示顺序。

公告列表（搜索、按状态筛选、排序、分页）

全部公告，不含已弃用的草稿。

required-privilege: syscfg:announcement:view
error-codes: []
Authorizations:
cookieAuth
query Parameters
keyword
string <= 128 characters

按标题模糊匹配。

status
string (AnnouncementStatus)
Enum: "DRAFT" "PUBLISHED" "WITHDRAWN"

DRAFT 草稿（商户不可见）/ PUBLISHED 已发布 / WITHDRAWN 已撤回（不能再发布）。

sortField
string
Enum: "createdAt" "publishedAt"

排序字段。不传 = 不排序；页面默认顺序由前端显式传。按 publishedAt 排序时未发布的恒在末尾。

sortOrder
string
Enum: "ascend" "descend"

排序方向;与端点自己的 sortField 配对,或作用于端点 description 声明的固定排序键。有排序键、未传本参数 = ascend;端点无排序键且未传 sortField 时本参数无效(不排序)

pageNum
integer >= 1
Default: 1

页码(从 1 计;分页)

pageSize
integer [ 1 .. 200 ]
Default: 20

每页记录数(默认 20;契约上限 200,部署可把实际上限配得更低——超出即 400)

新建公告草稿

新建一条草稿。草稿对商户不可见，发布用 publishAnnouncement。

  • 标题或正文为空 → 400。

幂等：Idempotency-Key。同键同请求体重发返回首次建的那条；同键改请求体 → 409·908003；首次请求还在处理 → 409·908002，稍后同键同请求体重发。

required-privilege: syscfg:announcement:manage
error-codes: []
Authorizations:
cookieAuth

string non-empty .*\S.*

发布公告

把草稿发给全体商户：发布那一刻状态正常的商户各自的站内信里出现这条公告，之后才开通的商户收不到。记发布人与发布时间，留下一条操作记录。站内信随后陆续生成，不随本次响应返回。

  • 公告不是草稿（已发布、已撤回）→ 409·308104，商户站内信不新增。
  • 公告不存在或已弃用 → 404。
