商户后台 交易管理 — 前端契约面 (0.23.0)

Download OpenAPI specification:

商户后台交易域的读 + 命令窗口：统一支付交易查询表（多维过滤 + 汇总卡）· 交易详情（含回调技术细节 + 换汇呈现）· 统一退款查询表 · 退款详情 · 支付 / 退款收据（PDF）· 数据导出（Excel）· 发起退款（凭 Refund PIN）· 撤销待处理退款 · 预授权完成（Release）。 交易 / 退款 / 预授权的状态机、清结算、Fee、通道交互归支付核心系统，本域只提供「可见 + 可操作」窗口。 金额一律最小币种单位整数 + currency；列表行不同标价币种不混算，汇总卡单一结算币种（把每笔实际结算到商户结算币种的金额相加，不按标价币种分组）；换汇信息在支付渠道给出了汇率或换算说明时有条件展示——标价 ≠ 结算币种为典型场景、非判定条件。 字段类型以本 spec 为准。 幂等：所有命令类端点必带 Idempotency-Key（缺失 → 400）。同键 + 同请求体重发返首次结果、不重复执行——网络重试请复用同一个键；改了请求体就必须换新键，沿用旧键改内容 → 409·208005。

payments

支付交易：查询表 / 汇总卡 / 详情 / 收据 / 导出（读）+ 发起退款 / 预授权完成（命令）。

统一支付交易查询表（过滤 + 排序 + 分页）

返回当前商户支付交易列表（服务端不设默认时间窗——页面默认今日由客户端决定并作为普通日期范围发出）。多维过滤（时间 / 支付方式〔品牌 Family〕/ 来源 / 状态）+ 关键词（订单号 / 备注模糊，金额数值精确、跨标价币种按数值命中）+ 排序 + 分页。 每行金额按其标价币种展示、不同币种不合并；行操作可见性（可退 / 收据）由后端返回。 汇总卡只统计计入营收的那几个状态（白名单见 PaymentStatus），但列表本身不筛——两者口径不同、别用卡片笔数去对列表行数。 查询超时 → 降级（展示「暂不可用」，不返回半截数据）。

status
string (PaymentStatus)
Enum: "PAID" "PARTIALLY_REFUNDED" "REFUNDED" "FAILED" "REJECTED" "PREAUTH_HOLDING"

支付订单商户可见状态：PAID 已收款 · PARTIALLY_REFUNDED 部分退款 · REFUNDED 全额退款 · FAILED 失败 · REJECTED 平台未受理 · PREAUTH_HOLDING 预授权挂起。 PAID / PARTIALLY_REFUNDED / REFUNDED 三者同属已收款、按已落账退款量区分（「已落账」= 通道受理成功；受理后失败会回退，故订单可能从 PARTIALLY_REFUNDED 退回 PAID）；REJECTED 未受理、FAILED 收款失败、PREAUTH_HOLDING 预授权挂起待放行。收款过程中的中间态不进列表。 REJECTED 与 FAILED 不可混用：REJECTED = 平台未受理该笔交易、支付从未发生（无支付尝试、不可退款、无收据，refundable / receiptAvailable 恒 false）；FAILED = 已尝试支付但失败。 计入营收类聚合（收款额 / 净额 / 笔数）的状态白名单（穷举）：PAID · PARTIALLY_REFUNDED · REFUNDED · PREAUTH_HOLDING——哪些页面有这类聚合、聚合字段叫什么，见该页契约。 不计入聚合 ≠ 不在列表：本 enum 的每个取值都可能作为列表行出现（FAILED / REJECTED 亦然）、并可按状态单独筛出——别以为列表只给成功单。 封闭 enum（取值集固定、可穷举分支）；仍须 unknown-safe 处理未识别值（保守对待、不静默丢弃）。

交易页头汇总卡（随筛选、单一结算币种）

返回与 listPayments 同筛选上下文的汇总卡：交易笔数（币种无关计数）+ 单一结算币种（把每笔实际结算到商户结算币种的金额相加得出，不按标价币种分组）的 Gross Sales / Refund Amount / Net Sales + To Settle。 与列表同轴：Gross Sales / transactions 与 listPayments 用同一组筛选参数、同一批交易进这两个数， 但汇总卡只统计白名单四态——计入的状态是 PAID / PARTIALLY_REFUNDED / REFUNDED / PREAUTH_HOLDING（穷举）， FAILED / REJECTED 不计入（钱从未收到）；而列表把这两态也一并列出，故汇总卡笔数通常小于列表行数。 金额不要靠加总列表行来核对——行金额是该笔的标价币种（同一商户可同时有不同标价币种的收款码）， Gross Sales 是结算币种合计；可核对的是「哪些行计入了汇总」与笔数。 refundAmount / netSales 是本页专有量——分别为筛选退款额（按退款当前状态投影）与筛选净收款额（= Gross − 筛选退款额）， 与 Dashboard 的 Refund Amount / Net Sales 口径不同、两者不可互推（别跨页对数）； 其中筛选净收款额的两个分量口径不同，不参与逐行核对承诺。 To Settle 为账户账务的资金派生值、不由交易筛选条件重算（结算币种口径）。

导出支付交易（按当前筛选全集 Excel）
