商户后台 系统 — 前端契约面 (2.0.0)

Download OpenAPI specification:

商户后台 React SPA 消费的系统契约：平台参考数据（/config/*）、站内信（/notices）、开发者接入（/developer）。 浏览器持 httpOnly 会话 cookie，字段类型与校验规则以本 spec 各字段为准。

  • cookieAuth 的非安全方法一律带 X-CSRF-Token。
  • 参考数据与当前商户无关；站内信与开发者接入以会话的当前商户为准、不看请求体，当前商户不可访问时返回 409·208022。

平台参考数据

平台参考数据（与当前商户无关）：币种国家组合、国家与省州、行业与 MCC、支付方式与标准费率、结算周期与账户制式。

结算币种及各币种可选的国家

有效的结算币种 × 国家组合，平台配置、和当前商户无关。用在 Add Merchant 弹窗与入驻向导 Business 步：先选币种或国家，另一项按组合联动；提交的组合不在这里 → 400。

登记或替换商户签名公钥

登记当前商户的 RSA 公钥，平台用它验商户请求的签名。还没登记时是首次登记，已登记时是替换。

  • 公钥为空、不是 PEM 或不是 RSA 公钥 → 400·204011，不产生任何变更。
  • 替换后新公钥立即可用，被换下的那把在宽限期内仍然有效（默认 24 小时，由平台设定）。宽限期内再次替换，最早的那把立即失效。
  • 提交的公钥与当前这把相同：什么都不变，照常返回当前这把。
required-privilege: settings:developer:edit
error-codes: [204011]
Authorizations:
cookieAuth
header Parameters
X-CSRF-Token
required
string non-empty .*\S.*

CSRF 令牌(double-submit;cookie 会话鉴权的非安全方法[POST/PUT/PATCH/DELETE]必带;缺失/不匹配 → 403 fail-closed)。取值 = 本 BFF 可读伴生 CSRF cookie 的当前值(cookie 名 per-BFF、见该面 cookieAuth 说明;建会话时随会话 cookie 一起下发、同生命周期),每次请求现读、不要缓存。
